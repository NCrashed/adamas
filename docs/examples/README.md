# Примеры кода на Adamas

Иллюстрации форм, которых компилятор **ещё не принимает**: эффекты и
handler'ы (Фаза 4), классы и модули (Фаза 3), записи, литералы, числовая
иерархия. Материал для чтения человеком.

То, что компилируется сегодня, лежит в `tests/golden/` — там программы
прогоняются целиком, `adamas check` от текста до проверки типов, и ожидаемый
вывод под снапшотом. Пример, который можно проверить, принадлежит туда: здесь
он протух бы молча.

Синтаксис здесь не дублируется — источник истины один: §4 design'а. §4.1 —
базовый синтаксис, эффекты и handler'ы; §4.2 — записи; §4.4 — prelude,
операторы и фикситеты; §4.8 — модули и ordered scoping. Пример, разошедшийся
с §4, — баг примера.

Пока пусто, и это не забывчивость: непроверяемая копия §4 расходится с
оригиналом тем быстрее, чем она длиннее. Первые примеры появятся вместе с
формами, которые они показывают.
