Материал для §13 и §10 — записи в design вносит ведущий, здесь только то, что

Два отказа границы сняты прогоном `adamas check`, и они разные:

```
extern "C" fn f : Array n UInt8 -> UInt64 -> Unit
  имплисит через границу C не идёт: значения в рантайме у него нет,
  а полиморфный аргумент уровню 1 переносить нечем (§5.3)

extern "C" fn f : Array 8 UInt8 -> UInt64 -> Unit
  параметр через границу C не идёт: уровень 1 переносит машинное слово -
  примитив §4.11, `CPtr` или единицу (§5.3)
```

Первый важнее второго: длина массива у всякого буфера — переменная, и
auto-lift §4.1 кладёт её стёртым имплиситом **перед** буфером. То есть путь (б)
упирается в стёртое связывание раньше, чем в сам массив.

## Подтверждено чтением рантайма

`crates/adamas-runtime/c/array.c` и `include/adamas.h`:
`_Static_assert(sizeof(adamas_array) == 24)`, нагрузка со смещения 24, страйд в
заголовке, `payload(array) = (char *)array + sizeof(adamas_array)`. У плоского
массива (`stride != 0`) там байты подряд. Одолжить плоский массив чужой
стороне — **вычисление адреса**, а не копия.
