# Golden fixtures

Языковые фикстуры: исходники на Adamas плюс ожидаемый вывод компилятора.
Данные, не Rust-код.

Директория лежит в корне, а не внутри крейта, потому что одни и те же
фикстуры прогоняются несколькими слоями: парсером (Фаза 2), элаборатором
(Фаза 1–2), драйвером. Дублировать их по крейтам — гарантированный дрейф.

Rust-код, который их читает, живёт в `crates/<crate>/tests/` — cargo
подхватывает `tests/` только внутри пакета, и в корне virtual workspace эта
директория компилятором сборки не видна.

## Ожидаемая раскладка

```
tests/golden/
  parse/        <name>.adamas + <name>.expected   — Фаза 2
  elaborate/    <name>.adamas + <name>.expected   — Фаза 1–2
  errors/       <name>.adamas + <name>.stderr     — диагностика (§7.4)
```

Ожидаемые результаты для type checker'а и элаборатора ведутся через `insta`
(`cargo insta review`), а не правятся руками.

Пока пусто: первые фикстуры появляются вместе с парсером в Фазе 2
(`adamas-design.md` §9).
