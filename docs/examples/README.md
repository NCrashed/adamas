# Примеры кода на Adamas

Иллюстративные программы для документации и обсуждений. Ничего из этого пока
не компилируется — парсера нет до Фазы 2 (`adamas-design.md` §9).

Синтаксис здесь не дублируется — источник истины один: §4 design'а. §4.1 —
базовый синтаксис, эффекты и handler'ы; §4.2 — записи; §4.4 — prelude,
операторы и фикситеты; §4.8 — модули и ordered scoping. Пример, разошедшийся
с §4, — баг примера.

Отличать от `tests/golden/`: там фикстуры, которые прогоняются автоматически,
здесь — материал для чтения человеком.
