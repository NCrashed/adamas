# Утечка стирания: стёртый аргумент, который строится в рантайме

Замер трека C волны 5 Фазы 9. Найден не поиском дефекта, а ценой: зависимый ECS
стоил **четыре блока кучи на кадр** там, где та же программа без завтипов стоит
нуля, и `@fbip` при этом проходил на обеих функциях - то есть форма кода reuse'у
не мешала.

## Что наблюдается

| форма | блоков на 1000 проходов |
|---|---|
| `leak.adamas` - стёртый индекс, стёртое доказательство от него, нестёртый носитель того же индекса | **2001** |
| `tight.adamas` - то же без доказательства | **1** |

Два блока на проход - это ровно `big = B (B A)`, то есть **стёртый аргумент
строится заново на каждом вызове**.

## Условие тройное, и лишнего в нём нет

Сужалось по одному, и каждое сужение - прогон:

| что стоит в сигнатуре | блоков на 1000 |
|---|---|
| `(0 x : T) -> UInt64 -> UInt64` | 0 |
| `(0 x : T) -> (0 p : Proof x) -> UInt64 -> UInt64` | 0 |
| `(0 x : T) -> Box x -> Box x` | 1 |
| `(0 x : T) -> (0 p : Proof x) -> Box x -> Box x` | **2001** |

Течёт, значит, не «зависимый стёртый аргумент» и не «индексированный носитель», а
**оба разом**: от одного стёртого значения зависят и второй стёртый аргумент, и
нестёртый.

Первая гипотеза была «зависимый стёртый аргумент сам по себе» - она **не
воспроизвелась**, и это записано здесь, чтобы её не выдвинули снова.

## Почему это заметили поздно

Стёртое поле конструктора проверялось раньше и выглядело бесплатным: мир с
добавленным `(0 d : Idx)` давал те же пять блоков. Проверка была негодной -
значением поля стоял `Zero`, нульарный конструктор, и построить его стоит нуля
блоков при любом поведении компилятора. Различает только **составное** значение.

## Чего это стоит демо

Не блокер: горячий путь специализируется без параметров-доказательств, и тогда
600 кадров стоят семи блоков вместо 2407. Зависимый API остаётся на границе.
Но это обход, а не лечение, и записан он вопросом в §10.

## Условия

Режимов сборки в языке нет; числа сняты с `adamas build --backend c`. Счётчик -
рантаймовский (`блоков выдано N`), он же считает и копии массивов.

## Как повторить

```sh
cd docs/measurements/erased-leak
cp leak.adamas main.adamas && adamas run --backend c main.adamas    # блоков 2001
cp tight.adamas main.adamas && adamas run --backend c main.adamas   # блоков 1
```
