# `noalias` на векторном ядре: время, а не инструкции

Вопрос §10 233. Решение 2026-09-15 «метаданных алиасинга бэкенд не эмитит»
стояло на нуле инструкций разницы на трёх нагрузках. После того как циклы
`workload-vector` стали доказывать номер ячейки леммами, а не проверкой на
шаге, `noalias` у каждого указательного параметра меняет код: 8680
инструкций против 8665. Инструкций с ним **больше**, и сколько это стоит по
времени, никто не мерил. Здесь - мера.

## Условия

| что | значение |
|---|---|
| коммит | `47143b63` плюс пара в стенде (`benches/workloads.rs`, `unaliased`) |
| хост | Intel Core i7-12700H, Linux 6.18 |
| привязка | `taskset -c 8` - один логический процессор P-ядра |
| стороны | LLVM-путь с `noalias` у каждого указательного параметра против LLVM-пути как есть; правка та же, что у `tests/alias.rs`, и та же щедрость |
| оценка | чередование двух бинарей в одном окне (`harness::ratio`), свой пол у каждой стороны, медиана по четырём тишайшим блокам из семи |
| прогонов | пять подряд |

## Числа

Отношение - время с `noalias` к времени без, за вычетом полов; меньше единицы
значит «с `noalias` быстрее».

| прогон | отношение | размах блоков | запас |
|---|---|---|---|
| 1 | 0.9920 | 0.0045 | 219.8x |
| 2 | 0.9920 | 0.0087 | 114.4x |
| 3 | 0.9917 | 0.0117 | 84.8x |
| 4 | 0.9993 | 0.0159 | 62.9x |
| 5 | 0.9942 | 0.0024 | 422.5x |

**Медиана 0.9920, размах между прогонами 0.0076.** Выигрыш - около 0.8 %, то
есть того же порядка, что разброс между прогонами: четвёртый прогон даёт
практически единицу. Ответ и число выданных блоков одинаковы у обеих сторон.

## Вывод

Метаданное больше не даровое по инструкциям, но и не покупает ничего, что
отличалось бы от шума. Мерилась к тому же **щедрая** правка, в общем случае
незаконная: разделяемый объект со счётчиком ссылок вправе прийти в два
параметра сразу. Законная - `noalias` только на параметрах с доказанной
уникальностью - даёт заведомо не больше. Решение 2026-09-15 остаётся: эмиттер
`noalias` не ставит. Пара в стенде остаётся свидетелем: отрыв больше
межпрогонного размаха будет виден сразу.

## Воспроизвести

```
nix develop --command bash -c 'taskset -c 8 cargo bench -p adamas-codegen --bench workloads -- vector 2>&1 | grep "против эмиттера"'
```

Пять раз подряд; в таблице - строка «по 4 тишайшим блокам» каждого прогона.
